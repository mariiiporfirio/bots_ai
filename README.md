<h1>📌 Construção de Bots com IA (Senac SP)</h1>

<h2>🚀 Sobre o Projeto</h2>
<p>
Este repositório reúne o projeto desenvolvido no <strong>curso livre “Construção de Bots com IA” do Senac São Paulo</strong>. 
O curso ensina a criar e treinar um chatbot que simula atendimento natural e humanizado usando lógica, estrutura de dados, 
algoritmos e técnicas de inteligência artificial.
<a href="https://www.sp.senac.br/cursos-livres/curso-de-construcao-de-bots-com-ia">[sp.senac.br]</a>
</p>

<h3>🧠 Objetivo</h3>
<ul>
  <li>Responder perguntas dos usuários de forma natural;</li>
  <li>Treinar modelos de IA para melhorar respostas;</li>
  <li>Integrar o bot a plataformas de mensageria.</li>
</ul>

<hr>

<h2>📚 O que foi aprendido</h2>
<ul>
  <li>Construção de chatbots com lógica de IA;</li>
  <li>Treinamento de bots com algoritmos de aprendizado de máquina;</li>
  <li>Publicação do bot em canais de atendimento e redes sociais;</li>
  <li>Configuração de ambiente de desenvolvimento;</li>
  <li>Testes, classificação de dados e ajustes do modelo;</li>
  <li>Definição de infraestrutura de armazenamento.</li>
</ul>
